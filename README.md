# D-TEK SOLAR ☀️

SEO-optimized, lightweight website built for a solar installation company. Designed to build trust, rank locally, and convert visitors into qualified leads through fast loading + clean UX.


**Live Demo**: https://d-tek.netlify.app


---

### Overview
D-TEK SOLAR needed a website that builds trust with homeowners and captures leads for solar installations. Built a lightweight, SEO-focused site with minimal JavaScript and optimized assets. Goal: rank in local city searches + get more quote requests without slowing down the site.

### Key Features
- **Lead Capture Form**: Contact form for instant quote requests with validation
- **Local SEO**: Meta tags, schema markup, and content optimized for city-based searches
- **Fast Loading**: Minimal JS, lightweight assets, scores 90+ on PageSpeed
- **Trust Signals**: Clean layout, testimonials section, and clear CTAs to build credibility
- **Mobile-First**: Responsive design that works perfectly on all devices

### Tech Stack
`HTML5` `CSS3` `Vanilla JavaScript` `SEO` `Responsive Design` `Netlify Forms`

### Result
Clean, trustworthy site that converts visitors into inquiries. Lightweight code means fast load times even on poor network. Optimized for "solar installation [city]" searches to bring in local leads.

### What I Learned
- **SEO**: Implemented structured data + meta tags to improve local search ranking
- **Performance**: Kept JS under 20KB and used WebP images to hit sub-2s load time
- **Conversion**: Placed CTAs above the fold + added trust badges to increase form submissions
- **Next**: Add blog section for content marketing + integrate Google Analytics 4
